# 审计 Rubric：风险等级怎么定

每条 claim 按下面两步定级。先看"背调员会怎么核"，再看"对得上吗"。

## 核查方式

| 方式 | 含义 | 例子 |
|---|---|---|
| `hr_call` | 打电话给前公司 HR | 在职时间、职位、是否在职 |
| `reference` | 证明人访谈 | 工作内容、谁主导的项目 |
| `payroll` | 银行流水 / 工资单 | 薪资、发薪公司名称 |
| `xuexinwang` | 学信网 | 学历、毕业时间 |
| `public_info` | 公开信息 | 公司规模、融资新闻、证书官网 |

## 定级

**高风险**：背调员按正常流程一核就会穿帮。

- 时间打架（两段全职重叠）
- Title 膨胀（专员→主管；组织架构可查）
- 数字无任何出处（自己也说不清证据在哪）
- 学历/证书造假（学信网、官网一键可查）
- 薪资虚报 20%+（银行流水）

**中风险**：需要解释，解释不清就升级。

- 空窗期无说明（问起来答得支吾）
- 模糊日期（只有年份，精确到月就对不上）
- 百分比无基数（"提升 300%"不说从多少到多少）
- "精通/主导"等词，但细节经不起追问
- 团队业绩写成个人（前同事一问便知）

**低风险**：可验证，证据在手。

- 日期精确到月，和离职证明一致
- 数字有报表/后台截图，能当场拿出来
- 证书在有效期内，名称准确

## 拿不准时

往高定一级，并写清楚为什么拿不准。宁可误报，不可漏报——漏掉一个高风险，比多标三个中风险严重得多。

## 修复建议写法

只许三种：

1. **删掉**：这句留着就是雷，直接删。
2. **改成真的**：给出改写后的句子，必须是事实。
3. **准备证据**：说清楚证据是什么、放在哪、背调时怎么出示。

永远不许写"怎么让这句通过背调"。那是另一条路，不在这。
